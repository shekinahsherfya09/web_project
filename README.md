# School Fee Management System

A full stack web application to manage student details and fee payments.

**Tech stack:** React JS, Bootstrap, Node.js, Express.js, MongoDB

## Features
- Add, view, update and delete students
- Record fee payments and view payment history
- Calculate pending fees for each student

## How to run

Make sure Node.js and MongoDB are installed and MongoDB is running.

### Backend
```
cd backend
npm install
npm run dev
```
Runs on http://localhost:5000

### Frontend
```
cd frontend
npm install
npm run dev
```
Runs on http://localhost:5173
